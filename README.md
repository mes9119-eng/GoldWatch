# مراقب الذهب (Gold Watch)

تطبيق أندرويد خفيف بدون إعلانات:
- ودجت للشاشة الرئيسية بسعر جرام الذهب بالريال لعيار 21 و24 و18، مع نسبة التغير اليومية
- تنبيه عند الارتفاع فوق حد تحدده أو النزول تحت حد تحدده
- تحديث تلقائي كل 15 دقيقة تقريباً

مصدر السعر: gold-api.com (والاحتياطي goldprice.org)، يتحول للريال على سعر 3.75.
